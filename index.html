Agents

MetricCollector

Ingest, normalize, and aggregate metrics from multiple sources

AnomalyDetector

Statistical anomaly detection using z-score, trend, and seasonal analysis

AlertManager

Alert rule evaluation with cooldown, escalation, and suppression

LogAnalyzer

Log pattern detection, error classification, and insight extraction

TraceCorrelator

Distributed trace correlation and critical path analysis

CapacityPlanner

Resource usage forecasting and capacity exhaustion prediction

Components

  • RuleEngine - Multi-condition alert rules with cooldown and escalation
  • MetricsProcessor - Real-time dashboard with 10 default widgets
  • TopologyMapper - Service dependency mapping from traces
  • IncidentManager - Full incident lifecycle with auto-escalation
  • TimeSeriesStore - Efficient TS storage with aggregation and downsampling
  • ObservabilityDatabase - In-memory DB with indexing and query API
  • PrometheusConnector - PromQL builder + API integration
  • DatadogConnector - Metrics, APM, and dashboard integration

Quick Start

from src.core.orchestrator import Orchestrator
from src.agents import *

orch = Orchestrator()
orch.register_agent("metric_collector", MetricCollectorAgent())
orch.register_agent("anomaly_detector", AnomalyDetectorAgent())
orch.register_agent("alert_manager", AlertManagerAgent())
orch.register_agent("log_analyzer", LogAnalyzerAgent())
orch.register_agent("trace_correlator", TraceCorrelatorAgent())
orch.register_agent("capacity_planner", CapacityPlannerAgent())

results = orch.run_pipeline(metrics)
